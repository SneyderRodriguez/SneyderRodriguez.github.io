## 📌 Sobre el proyecto

Este proyecto corresponde a mi **portafolio web personal**, desarrollado para presentar de manera clara y visual mi perfil profesional, habilidades técnicas, experiencia en desarrollo web y proyectos realizados.

La página está construida con tecnologías web fundamentales como **HTML5, CSS3 y JavaScript**, incorporando un diseño responsive y diferentes componentes interactivos para mejorar la experiencia de navegación.

El portafolio también funciona como un punto de acceso a los diferentes proyectos que he desarrollado durante mi proceso de formación y crecimiento como desarrollador **Full-Stack Java**.

---

## 👨‍💻 Sobre mí

> **"Una simple falla de hardware despertó mi curiosidad; la programación hizo el resto."**

Soy **Ingeniero de Sistemas** con enfoque en desarrollo **Full-Stack Java**.

Mi interés por la tecnología comenzó a partir de una situación sencilla: una batería de reloj fue suficiente para impedir que un computador encendiera. Aquella experiencia despertó mi curiosidad por comprender cómo funcionaban los equipos y posteriormente me llevó a estudiar Ingeniería de Sistemas y adentrarme en el mundo de la programación.

Actualmente continúo fortaleciendo mis conocimientos en desarrollo web, creando aplicaciones funcionales y explorando diferentes tecnologías para mejorar mis habilidades como desarrollador Full-Stack.

**Tecnologías:** Node.js · JavaScript · APIs REST · OAuth 2.0

## 🖥️ Ejecutar el proyecto localmente

Como se trata de un proyecto web estático, puedes ejecutarlo directamente desde tu equipo.

### 1. Clonar el repositorio

```bash
git clone https://github.com/SneyderRodriguez/PORTAFOLIO.git
```

### 2. Entrar al proyecto

```bash
cd PORTAFOLIO
```

### 3. Ejecutar

Puedes abrir directamente el archivo:

```text
index.html
```

También puedes utilizar una extensión como **Live Server** en Visual Studio Code para ejecutar el proyecto mediante un servidor local.
