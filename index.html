Acerca de mí

Una simple falla de hardware despertó mi curiosidad; la programación hizo el resto.

Ingeniero de Sistemas con enfoque en desarrollo Full-Stack Java.

Mi camino comenzó cuando descubrí cómo una simple pila de reloj impedía que un PC encendiera.

Esta sorpresa me llevó a estudiar Ingeniería de Sistemas, donde descubrí la programación.

Actualmente continúo aprendiendo y desarrollando aplicaciones web, buscando crear soluciones funcionales y seguir creciendo como desarrollador Full-Stack.

Proyectos

Proyecto 1: Tienda Online

Friticos Colombia

Detalles

Plataforma web gastronómica desarrollada con HTML5, CSS3, JavaScript Vanilla y Bootstrap 5.

Cuenta con un catálogo dinámico de productos típicos colombianos, carrito de compras interactivo con almacenamiento en `localStorage`, panel lateral desplegable y navegación fluida adaptada a cualquier dispositivo.

Proyecto 2: Adopta una máscota

Patitas Felices

Detalles

Plataforma web de adopción de mascotas desarrollada con HTML5, CSS3 y Bootstrap 5. Dispone de catálogo de peluditos, modal interactivo para solicitudes, sección institucional y formulario de contacto.

Diseñada bajo un enfoque responsivo, utiliza CSS Grid, Flexbox, tipografías de Google Fonts y una paleta visual definida mediante variables CSS globales.

Proyecto 3: Portal Web

Sabores de la Plaza

Detalles

Plataforma web responsiva diseñada para un colectivo gastronómico local. Construida con HTML5, CSS3 y Bootstrap 5, la interfaz integra carruseles interactivos, tablas de precios, menús adaptables y un sistema de pedidos.

Destaca por su maquetación modular y una identidad visual personalizada mediante fuentes web y variables de color terracota.

Proyecto 4: Planificador de Tareas

Thyra

Detalles

Aplicación web para la gestión y seguimiento de tareas. Construida con JavaScript (ES6+), HTML5 y CSS3, permite crear, categorizar, asignar prioridades y definir fechas límite a distintas actividades. Incluye control de estados (por hacer, en progreso, finalizado), persistencia de datos local mediante localStorage y un modal interactivo para consultar el detalle de cada tarea.

Proyecto 5: APIs

WoW API

Github próximamente Demo próximamente

Detalles

Es una aplicación desarrollada para explorar la integración con la API de World of Warcraft. Busca implementar autenticación OAuth 2.0, consulta y procesamiento de datos del juego, y una API REST propia utilizando Node.js, aplicando buenas prácticas de desarrollo y manejo de errores.

Proyecto 6: Sistema de Reservas

HuellaVet

Detalles

Plataforma web de agendamiento veterinario desarrollada con HTML5, CSS3, JavaScript, Spring Boot y MySQL. Permite a propietarios registrar sus mascotas y reservar citas en tiempo real según la disponibilidad de un médico veterinario independiente, ofreciendo un panel administrativo para la gestión integral de agenda e interfaz adaptable a cualquier dispositivo.
